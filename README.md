# 30 ball.uz

Telegram Mini App для абитуриентов Узбекистана — обязательный блок вступительного экзамена (математика, история, родной язык и литература). Полное техзадание и правила работы — в [CLAUDE.md](./CLAUDE.md).

## Как запустить локально

1. Скопируйте `.env.example` в `.env` и заполните реальными значениями (токен бота, строки подключения к базе — см. раздел ниже).
2. Установите зависимости и накатите схему базы:
   ```
   npm install
   npm run db:migrate
   ```
3. Запустите сервер разработки:
   ```
   npm run dev
   ```
   Откроется на http://localhost:3000 — но полноценно приложение работает только внутри Telegram (см. «Как проверить в Telegram» ниже).

## Переменные окружения

Смотрите `.env.example` — там описано, что означает каждая переменная. Реальные значения хранятся только в `.env` (не коммитится в git).

## Как проверить в Telegram

1. Задеплойте приложение (Vercel подхватывает пуш в `main`).
2. Один раз после деплоя пропишите вебхук боту:
   ```
   npm run bot:set-webhook -- https://<ваш-домен>/api/telegram-webhook
   ```
3. Откройте бота в Telegram, отправьте `/start` — придёт кнопка «Открыть».

## Структура проекта

- `/app` — маршруты Next.js (страницы и API)
- `/components` — переиспользуемые React-компоненты
- `/lib` — конфигурация приложения, проверка Telegram, сессии, работа с базой
- `/prisma` — схема базы данных и миграции
- `/scripts` — служебные скрипты (настройка вебхука бота и т.д.)
- `/tests` — тесты (Vitest)
- `apps.config.ts` — конфигурация конкретного приложения семьи (название, палитра, предметы)
